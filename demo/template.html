Tech Abuse Patterns

A dashboard for domestic violence advocates, funders and legislators in Mississippi. It shows which kinds of technology-facilitated abuse are rising, where, and how quickly survivors get a safety plan, without ever showing an individual.

Switch to the smaller dataset to see protection at work: with fewer records, more counts fall below 11 and are hidden.

How the numbers are protected

  • Only totals are shown. No individual record reaches this page.
  • Any count below 11 is hidden, along with any number that could be used to work one out.
  • A 0 means no reports. Zeros are never hidden, because gaps in support matter.
  • The finest detail recorded is a multi-county region and a calendar quarter.
  • The page re-checks the data before showing it, and refuses to display anything that fails.
